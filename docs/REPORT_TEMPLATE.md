# Focused upstream report

Keep filled reports and coordination private. Publish an issue only when its
content is authored and contains no game/BIOS bytes or game-derived source.

- Tool full revision, runtime ABI, compiler/target/options and binary SHA256.
- Disc, BIOS, initial BRAM, boot payload and generated module identities.
- Execution tier, logical PC, full eight-byte MPR mapping, physical fetch
  addresses and source content identity; dynamic overlay history if relevant.
- Small bounded input recipe, frame/tick/step limits and expected-byte assists.
- Expected versus observed behavior, first failing boundary and repeatability.
- Independent reference evidence, version/identity, compared scope and limits.
- Authored synthetic reproducer where feasible; separate shared-tool defect
  from a title configuration or progression issue.
- Private receipt/log/route paths, input immutability and output accounting.
- Material change since the prior report, proposed upstream ownership, and
  exact affected retest request. Avoid unchanged status message loops.
